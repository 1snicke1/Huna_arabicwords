# Huna Arabic — карточки (Telegram Mini App)

Приложение для заучивания арабских слов из курса Huna Arabic (Тома I и II)
методом интервального повторения (spaced repetition), в духе Anki.

## Что внутри

- `index.html`, `style.css`, `app.js` — само приложение (без сборки, чистый JS)
- `words-data.js` — словарь: 771 слово с огласовками, разметкой по главам/
  диалогам и примерами использования из учебника, по обоим томам
- `assets/logo-mark.png` — логотип академии
- `api/bot-webhook.js` — serverless-функция поддержки (см. раздел
  "Поддержка" ниже)
- Все файлы статические — сборка не требуется (кроме одной serverless-
  функции для поддержки, которую Vercel подхватывает автоматически)

## Как это устроено

**Дизайн.** Палитра и стиль взяты напрямую с обложек учебников и сайта
huna-arabic.com: тёмно-синий градиент (`#020a1d → #00264b → #193d61`),
фирменный тил (`#2d6283` / `#35a9bf`) и акцентный оранжевый (`#ff7d1f`)
из диалогов учебника. Арабский текст — шрифт Noto Naskh Arabic (корректно
показывает огласовки), интерфейс — Manrope.

**Огласовки.** Изначальный Excel-словарь был без огласовок. Текст обоих
PDF-учебников был программно сопоставлен со словарём по буквенному
"скелету" слова (без учёта огласовок/пробелов/разделителей), после чего
огласовки перенесены из учебника в словарь посимвольно. Там, где слово
не встречалось в табличном виде в учебнике (числительные, дроби, цвета,
некоторые глагольные тройки), огласовки проставлены вручную по правилам
литературного арабского. Названия месяцев (январь–декабрь) намеренно
оставлены без огласовок — так их принято писать и в самом учебнике.
Итоговый исправленный словарь отдельно: `vocab_corrected.xlsx`.

**Интервальное повторение.** Логика повторяет модель Anki: у каждого слова
есть фактор лёгкости (EF), число повторений и дата следующего показа.
Пока слово только изучается (новое или недавно забытое), оно проходит
через короткие "обучающие" шаги — 1, 4, 10, 20 минут:
- **Забыл** — откатывает слово к самому первому (самому короткому) шагу:
  показывается чаще всего.
- **Трудно** — повторяет текущий шаг, не продвигая вперёд: слово всё ещё
  часто.
- **Хорошо** — продвигает на следующий шаг (реже), после последнего шага
  слово "выпускается" в долгосрочный график (интервал в днях).
- **Легко** — сразу выпускает слово в долгосрочный график, минуя
  оставшиеся шаги.

Если позже, уже в долгосрочном графике, слово снова забыто ("Забыл") —
оно возвращается в обучающие шаги, а не просто получает короткую
отсрочку. Слово, которое хорошо помнится, встречается всё реже и реже
(интервал растёт), пока не будет освоено; слово, которое даётся тяжело —
остаётся "на виду" и повторяется чаще, пока не будет закреплено. Внутри
одной сессии слово, отмеченное как трудное, возвращается уже через
несколько карточек — не нужно ждать следующего дня. Настраиваемый лимит
новых слов в день (по умолчанию 15).

**Отмена хода.** На экране повторения есть кнопка отмены (стрелка рядом
со счётчиком) — она возвращает к предыдущему слову и полностью отменяет
последнюю оценку (если случайно нажали не ту кнопку). Доступна только
для одного последнего действия.

**Разделы: главы и диалоги.** Слова размечены по структуре учебника —
16 глав ("Баб", сквозная нумерация через оба тома) и диалоги внутри
каждой главы (там, где они есть; вспомогательные страницы — числа,
цвета, упражнения — присоединены к диалогу, к которому они относятся).
На главном экране кнопка "Раздел" открывает список глав, каждую можно
выбрать целиком или раскрыть до отдельных диалогов — можно комбинировать
несколько глав/диалогов одновременно. Разметка построена автоматически
по заголовкам разделов в PDF учебников.

**Active Recall.** Карточка сперва показывает только слово на исходном
языке; перевод открывается по нажатию — это вынуждает вспоминать
значение активно, а не просто узнавать его.

**Два направления.** Каждое слово изучается сначала в направлении
арабский → русский (узнавание). Как только эта сторона "выпускается"
из обучающих шагов в долгосрочный график (т.е. пользователь уверенно
её помнит), автоматически открывается обратная карточка того же
слова — русский → арабский (воспроизведение по памяти, более сложный
навык). У направлений полностью независимое расписание повторений —
как две разные карточки в Anki с одной колоды note type "с обратной
стороной": можно уверенно узнавать слово по-арабски, но ещё учиться
вспоминать его написание, и наоборот. Обратные карточки используют тот
же дневной лимит новых слов, что и прямые (чтобы не перегружать сессию
одновременно и новыми словами, и новыми обратными карточками для уже
пройденных). Направление можно полностью отключить в Статистике
("Обратное направление RU → AR"), если нужна только сторона
арабский → русский.

**Контекст из учебника.** На обратной стороне карточки, под переводом,
показан пример настоящего использования слова — фраза из диалога
учебника с этим словом, выделенным цветом. Примеры извлечены
программно из PDF (реплики диалогов, сопоставленные со словом по
буквенному составу с учётом словоизменения) — для части словаря такой
пример нашёлся не для каждого слова: 516 из 771 (~67%), для остальных
блок с контекстом просто не показывается. Не бывает выдуманных
примеров — только то, что действительно есть в тексте учебника.

**Прогресс.** Хранится через Telegram CloudStorage (привязан к аккаунту
пользователя в Telegram, доступен с любого устройства). Если приложение
открыто вне Telegram (например, в обычном браузере при тестировании),
автоматически используется localStorage — тоже работает, но только на
этом устройстве и в этом браузере.

## Как опубликовать как Telegram Mini App

1. **Разместите файлы на HTTPS-хостинге.** Подойдёт любой статический
   хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages и т.п.
   Требование Telegram — обязательно HTTPS.
   Просто загрузите все файлы из этой папки как есть, ничего собирать
   не нужно.

2. **Создайте бота через [@BotFather](https://t.me/BotFather)** (если
   ещё нет): `/newbot` → укажите имя.

3. **Подключите Mini App:**
   `/newapp` → выберите бота → укажите название, описание, иконку и
   **URL, по которому размещён `index.html`** (из шага 1).

4. **Готово.** Теперь у бота есть кнопка/меню, открывающая приложение.
   Можно также добавить кнопку через `/mybots` → Bot Settings → Menu
   Button → указать тот же URL.

## Поддержка: чтобы пользователи писали боту, а вы это видели

По умолчанию бот, привязанный к Mini App через BotFather, не обрабатывает
сообщения — он существует только как "запускатор" приложения. В проект
добавлен `api/bot-webhook.js` — небольшая serverless-функция без базы
данных, которая различает три ситуации:

- **`/start`** — приветствие ("Ассаламу алейкум!") со ссылкой на само
  приложение. Никуда не пересылается.
- **`/support`** — сначала бот показывает две короткие подсказки
  (как снять дневной лимит слов; что проверить, если бот не отвечает)
  с кнопкой "Всё равно написать в поддержку" — только после нажатия
  бот просит написать вопрос (через Telegram-механизм "ответить на
  сообщение"); именно ЭТО следующее сообщение пересылается вам в
  личный чат с ботом. Случайные сообщения без `/support` не
  пересылаются — бот вместо этого подскажет написать `/support`.
  Текст подсказок — константа `SUPPORT_TIPS` в начале файла, можно
  смело менять под свои формулировки.
- **Ваш ответ** — когда вы отвечаете (Reply в Telegram) на пересланное
  сообщение, функция определяет исходного отправителя и доставляет ваш
  ответ ему.

**Настройка (после того как проект уже задеплоен на Vercel):**

1. Узнайте свой числовой Telegram ID — напишите `/start` боту
   [@userinfobot](https://t.me/userinfobot), он пришлёт ваш `Id`.
2. В Vercel: **Project → Settings → Environment Variables** — добавьте:
   - `BOT_TOKEN` — токен вашего бота (тот, что выдал @BotFather при
     создании; если забыли — `/mybots` → выберите бота → API Token)
   - `OWNER_CHAT_ID` — ваш ID из шага 1
   - `MINI_APP_URL` — ссылка, которую бот присылает по `/start`.
     Лучший вариант — прямая ссылка на приложение вида
     `https://t.me/huna_arabic_appbot/имя_приложения` (имя приложения
     задавали при `/newapp` в BotFather) — она открывает Mini App прямо
     в Telegram. Подойдёт и обычный https-адрес хостинга, но тогда
     приложение откроется как обычный сайт, а не как Mini App внутри
     Telegram. Если переменную не задать, бот просто не пришлёт ссылку.
3. **Redeploy** проект (Deployments → ⋯ → Redeploy), чтобы переменные
   подхватились.
4. Установите вебхук — один раз откройте в браузере (подставив свой
   токен и домен без угловых скобок):
   ```
   https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://<ваш-домен-на-vercel>/api/bot-webhook
   ```
   В ответ должно прийти `{"ok":true,"result":true,...}`.

Кнопка "Написать в поддержку" на экране статистики ведёт на
`t.me/huna_arabic_appbot` (username уже указан в `app.js`, константа
`SUPPORT_BOT_USERNAME`).

**Как пользоваться:** пользователь отправляет боту `/support`, пишет
вопрос в ответ на просьбу бота — сообщение придёт вам как пересланное.
Ответьте на него (именно Reply, не новое сообщение) — ответ уйдёт
исходному пользователю.

**Ограничение:** если пользователь в настройках приватности Telegram
скрыл "пересылку от себя", бот не сможет определить, кому отвечать —
в этом случае в вашем чате появится соответствующее уведомление.
Это редкая настройка, не критично для большинства пользователей.
